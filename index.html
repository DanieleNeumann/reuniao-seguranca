Usuários e acessos

Todos os usuários têm o mesmo acesso a todas as abas e funções. Crie um acesso para cada pessoa que precisar usar o sistema — a senha que você digitar aqui é provisória: no primeiro acesso, a própria pessoa define a senha dela.

As senhas são guardadas cifradas (SHA-256 com salt), nunca em texto puro. Os acessos ficam neste navegador e vão junto no backup .json — ao importar o backup em outro computador, os mesmos logins passam a valer lá.
