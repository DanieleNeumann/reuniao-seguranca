# Reunião de Segurança

Controle de presença das reuniões de segurança (DDS) e escala semanal de apresentadores.

Aplicativo de página única (HTML + JS, sem servidor). Os dados ficam salvos no navegador
de cada aparelho (localStorage) — use **Admin → Exportar backup (.json)** para levar os
registros de um computador a outro.

## Abas

- **Dashboard** — percentual de participação da equipe, gráfico por reunião e frequência
  mensal de cada integrante.
- **Reuniões / Chamada** — registro de presente / ausente / justificado por reunião.
- **Escala Semanal** — rodízio automático de quem apresenta a segurança em cada semana.
- **Admin** — importação da lista de participantes (CSV/Excel), cadastro manual e backup.
